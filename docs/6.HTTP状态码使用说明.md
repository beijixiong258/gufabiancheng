# HTTP状态码使用说明

> 项目接口约定见 [接口设计](./3.接口设计.md)，异常处理见 [后端公共机制](./4.后端公共机制.md)。

## 1. 本项目的状态策略

项目使用统一响应体：

```json
{
  "code": 200,
  "data": null,
  "message": "success"
}
```

当前处于学习和前后端联调阶段。只要异常已经被 `GlobalExceptionHandler` 捕获并转换成 `Result`，HTTP状态码保持 `200 OK`，实际处理结果由响应体中的 `Result.code` 表示。

例如Token失效：

```http
HTTP/1.1 200 OK
Content-Type: application/json
```

```json
{
  "code": 401,
  "data": null,
  "message": "Token无效。"
}
```

前端统一判断 `Result.code`，不以HTTP状态码判断业务是否成功。

## 2. Result.code约定

| `Result.code` | 含义 | 使用场景 |
| --- | --- | --- |
| `200` | 成功 | 查询、创建、修改或删除成功 |
| `400` | 参数或普通业务错误 | 参数格式错误、非法JSON或枚举值、账号重复、密码错误 |
| `401` | 未登录 | 未携带Token、Token无效、用户已不存在 |
| `403` | 没有权限 | 普通用户访问管理员接口 |
| `404` | 数据不存在 | 根据ID未找到目标数据 |
| `500` | 未知或内部错误 | 程序异常、数据库或AI调用失败 |

第一版只使用以上状态，不额外引入复杂业务码。

## 3. 401与403

```text
401：还不能确认当前用户身份。
403：已经确认身份，但当前用户没有所需权限。
```

示例：

```text
没有Authorization请求头                 → Result.code 401
Bearer Token不在Redis中                  → Result.code 401
普通用户访问/api/admin或/api/admin/开头的接口      → Result.code 403
```

## 4. 400、404与500

```text
账号重复                              → 400
原密码错误                            → 400
请求的用户或记录不存在                  → 404
数据库连接失败或未预料的程序异常          → 500
```

可预料的业务错误不应统一写成500。未知异常也不应转换成400。

## 5. 与CommonException的关系

可预料的错误统一抛出携带 `code` 和 `message` 的 `CommonException`：

```java
throw new CommonException(400, "账号已存在。");
throw new CommonException(401, "Token无效。");
throw new CommonException(403, "没有管理员权限。");
throw new CommonException(404, "用户不存在。");
```

`GlobalExceptionHandler`直接把异常内容写入统一响应：

```java
return Result.fail(e.getCode(), e.getMessage());
```

因为处理器直接返回 `Result`，这些已处理异常的HTTP状态保持200。

## 6. 其他异常

参数校验异常：

```text
Result.code = 400
message = DTO校验注解中的第一条提示
```

请求体JSON语法错误或DTO中的枚举值非法：

```text
Result.code = 400
message = 请求体格式错误。
```

未知异常：

```text
Result.code = 500
message = e.getMessage()
```

学习联调阶段允许返回 `e.getMessage()`，便于定位问题；不返回完整堆栈，也不主动回显密码、Token或API Key。

## 7. 边界说明

未进入或未被全局异常处理器处理的Spring错误，例如部分404或容器级错误，仍可能使用真实HTTP状态码。项目业务接口只要求：已转换成 `Result` 的响应由 `Result.code` 表示结果。
